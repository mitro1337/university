Stil Extern

Importul unei foi de stil pastrata intr-un fisier separat (css3.css) folosind eticheta <link>.

Continut css3.css:
em { background-color: #8000FF; color: white }
h1 { font-family: Arial, sans-serif }
p { font-size: 18pt }
.blue { color: blue }
Legarea in <head>:
<link rel="stylesheet" type="text/css" href="css3.css"/>

Avantaje:

  • Separare totala: Structura HTML ramane complet separata de regulile vizuale CSS.
  • Reutilizare globala: Acelasi fisier CSS poate fi partajat intre sute de pagini.
  • Cache: Browserul descarca fisierul o singura data si il retine in cache.
