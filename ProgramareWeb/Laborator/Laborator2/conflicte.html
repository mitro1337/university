Rezolvarea conflictelor in CSS

Mecanismul de cascadare stabileste ordinea de aplicare a regulilor atunci cand exista declaratii multiple concurente.

Etapele rezolvarii conflictelor:

  1. Determinarea tuturor regulilor aplicabile: Navigatorul identifica toate regulile din toate sursele (inline, intern, extern).
  2. Sortarea dupa importanta (!important): Declaratiile marcate cu !important au prioritate maxima.
  3. Sortarea dupa originea foii de stil: Autor > Utilizator > Navigator.
  4. Sortarea dupa specificitate: Inline (1,0,0,0) > ID (0,1,0,0) > Clasa/Pseudoclasa (0,0,1,0) > Tip element (0,0,0,1).
  5. Sortarea dupa ordinea specificarii: La aceeasi specificitate, regula declarata mai tarziu suprascrie regula anterioara.

Selectori din laborator

1. Selectori de tip si grupati
H1 { color: blue }
H1, H2 { color: blue }

Titlu H3

Ambele etichete primesc aceeasi culoare din declaratia comuna.

2. Selector bazat pe clasa
.IMPORTANT { color: red }

Acesta este un text obisnuit, dar urmatorul cuvant este IMPORTANT.

3. Selector bazat pe ID
#COPYRIGHT { font-size: small }
Toate drepturile rezervate (#COPYRIGHT).
4. Selector contextual
LI P { margin-top: 0mm }
TABLE .SMALL P { font-size: small }
  • Element parinte LI

    Paragraf interior stilizat contextual prin selectorul LI P.

Celula cu clasa SMALL (TABLE .SMALL P)
5. Pseudoclase pentru legaturi
A:LINK { color: green }
A:ACTIVE { color: red }
A:VISITED { color: blue }
A:HOVER { color: orange }

Treceti cu cursorul (hover) sau dati click (active)

6. Pseudoelemente FIRST-LETTER si FIRST-LINE
P.INITIAL:FIRST-LETTER { font-size: 200%; float: left }
P.INITIAL:FIRST-LINE { text-transform: uppercase }

acesta este un paragraf initial. Prima litera este letrina marita de 200%, iar prima linie a paragrafului este transformata in majuscule.

7. Combinarea selectorilor
TABLE P.INITIAL:FIRST-LETTER { font-size: 220%; float: left }

text inclus intr-un tabel caruia i se aplica selectorul combinat complex.
