Studiul rezolvarii conflictelor si a selectorilor CSS

Cand mai multe reguli CSS se aplica aceluiasi element, apare un conflict. Mecanismul de cascadare (Cascading) rezolva conflictele aplicand strict 5 pasi succesivi:

Algoritmul de rezolvare a conflictelor (W3C / Indrumar):

  1. Determinarea tuturor regulilor aplicabile: Navigatorul cauta toate regulile din toate sursele (stiluri externe, stiluri interne, stiluri inline) care se potrivesc elementului respectiv.
  2. Sortarea dupa importanta (!important): Declaratiile marcate cu !important au prioritate maxima fata de declaratiile normale.
  3. Sortarea dupa originea foii de stil: Regulile definite de proiectant / autor au prioritate fata de stilurile definite de utilizator, care la randul lor au prioritate fata de stilul implicit al navigatorului (user agent).
  4. Sortarea dupa specificitate: Un selector mai specific castiga in fata unuia generic:
    Stil Inline (1,0,0,0) > ID (0,1,0,0) > Clasa/Pseudoclasa (0,0,1,0) > Tip element (0,0,0,1).
  5. Sortarea dupa ordinea specificarii: Daca doua reguli au aceeasi importanta, aceeasi origine si aceeasi specificitate, castiga regula care apare mai tarziu in document (regula de la sfarsit suprascrie regula de la inceput).

Demonstratie live 3: Toti selectorii exemplificati in laborator

1. Selectori de tip si grupati
H1 { color: blue }
H1, H2 { color: blue }

Titlu H3 stilizat prin selector grupat

Ambele etichete h2 si h3 primesc aceeasi culoare din declaratia comuna.

2. Selector bazat pe clasa
.IMPORTANT { color: red }

Acesta este un text obisnuit, dar urmatorul cuvant este IMPORTANT.

3. Selector bazat pe ID
#COPYRIGHT { font-size: small }
Toate drepturile rezervate. Element unic identificat prin ID #COPYRIGHT.
4. Selector contextual (Descendent)
LI P { margin-top: 0mm }
TABLE .SMALL P { font-size: small }
  • Element parinte LI

    Paragraf interior stilizat contextual prin selectorul LI P.

Text in celula cu clasa SMALL (stilizat prin TABLE .SMALL P)
5. Pseudoclase pentru legaturi (A:LINK, A:HOVER, A:ACTIVE)
A:LINK { color: green }
A:ACTIVE { color: red }
A:VISITED { color: blue }
A:HOVER { color: orange }

Interactiuni cu link-urile:
Plimba cursorul aici (hover - portocaliu) si da click (active - rosu)

6. Pseudoelemente FIRST-LETTER si FIRST-LINE
P.INITIAL:FIRST-LETTER { font-size: 200%; float: left }
P.INITIAL:FIRST-LINE { text-transform: uppercase }

acesta este un paragraf demonstrativ initial. Prima litera este o letrina marita de 200% cu float left, iar intreaga prima linie a paragrafului este transformata automat in majuscule.

7. Combinarea tipurilor de selectori
TABLE P.INITIAL:FIRST-LETTER { font-size: 220%; float: left }

text inclus intr-un tabel HTML caruia i se aplica selectorul combinat complex. Doar paragrafele cu clasa INITIAL aflate in interiorul unui TABLE primesc aceasta letrina portocalie.
