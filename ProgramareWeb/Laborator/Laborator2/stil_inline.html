Modalitatea 1: Specificarea stilului in cadrul unui element HTML

Aceasta modalitate utilizeaza atributul style atasat direct tag-ului HTML. Stilul afecteaza exclusiv elementul respectiv, avand cea mai mare specificitate la nivel de element (fara !important), dar incalca principiul separarii continutului de prezentare si ingreuneaza mentenanta.

Codul sursa din indrumar:
<p style="font-size: 20pt">Text</p>
<p style="font-size: 20pt; color: #0000FF">Text</p>
Rezultatul randarii in navigator:

Text (marime font 20pt, culoare implicita)

Text (marime font 20pt, culoare #0000FF - albastru)

Observatii didactice:

  • Atributul style: Permite specificarea uneia sau mai multor perechi proprietate: valoare; direct in tag-ul HTML.
  • Sintaxa: Fiecare declaratie este separata prin punct si virgula (;), iar proprietatea este separata de valoare prin doua puncte (:).
  • Dezavantaj: Daca se doreste modificarea culorii pe 50 de paragrafe, fiecare paragraf trebuie editat individual. Nu permite reutilizarea regulilor de stil.
