Studiu comparativ: Cele trei modalitati de precizare a stilului

Standardul CSS permite aplicarea stilului asupra unui document HTML in trei moduri distincte. Mai jos este prezentat un tabel comparativ complet, insotit de exemple interactive direct in pagina.

Criteriu 1. Stil Inline 2. Stil Intern (Antet) 3. Foaie de Stil Externa
Unde se declara In cadrul tag-ului HTML, prin atributul style="..." In interiorul <head>, prin tag-ul <style> Intr-un fisier extern .css, legat prin <link>
Sfera de aplicare Exclusiv elementul respectiv Toate elementele din pagina curenta Toate paginile site-ului care includ fisierul
Prioritate (Specificitate) Foarte mare (suprascrie stilul intern si extern) Medie (suprascrie stilul extern de specificitate egala) Baza de stilizare (prioritate normala)
Separare continut / stil Slaba (amesteca marcajul cu stilul) Medie (sunt in acelasi fisier, dar in zone diferite) Excelenta (separare perfecta de responsabilitati)
Cache in navigator Nu exista cache separat Nu exista cache separat Da, fisierul .css este salvat in cache
Recomandare practica Doar pentru teste rapide sau stiluri dinamice JS Pentru stiluri specifice unei singure pagini izolate Standardul industrial pentru toate proiectele web
