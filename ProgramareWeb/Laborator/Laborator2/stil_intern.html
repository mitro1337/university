Modalitatea 2: Specificarea stilului in antetul documentului HTML

Aceasta modalitate utilizeaza elementul <style type="text/css"> plasat in interiorul sectiunii <head>. Regulile definite aici se aplica tuturor elementelor corespunzatoare din cadrul aceleiasi pagini HTML.

Codul sursa din antetul <head> (conform indrumarului):
<style type="text/css">
    em { background-color: #8000FF; color: white }
    h1 { font-family: Arial, sans-serif }
    p { font-size: 18pt }
    .blue { color: blue }
</style>

Observatii didactice:

  • Centralizare locala: Stilurile sunt definite o singura data in antet si refolosite de mai multe tag-uri (ex: clasa .blue este aplicata atat pe <h1>, cat si pe <p>).
  • Elementul <em>: Are fundal violet (#8000FF) si text alb (color: white), suprascriind stilul parintelui p.blue.
  • Limitare: Regulile se aplica doar paginii curente. Daca site-ul are 20 de pagini, stilul trebuie duplicat in fiecare fisier HTML.
