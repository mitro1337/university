Stil Intern

Specificarea stilului in interiorul sectiunii <head> folosind eticheta <style>.

Cod sursa:
<style type="text/css">
    em { background-color: #8000FF; color: white }
    h1 { font-family: Arial, sans-serif }
    p { font-size: 18pt }
    .blue { color: blue }
</style>

Observatii:

  • Centralizare locala: Regulile se definesc o singura data in antet si se aplica tuturor elementelor corespunzatoare din pagina.
  • Elementul <em>: Are fundal violet (#8000FF) si text alb (color: white).
  • Limitare: Regulile se aplica doar documentului HTML curent.
