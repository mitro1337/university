Exercitiul 3.2: Crearea si stilizarea unui meniu vertical in CSS

Spre deosebire de meniul orizontal (care utilizeaza display: inline sau display: inline-block), meniul vertical pastreaza orientarea implicita pe coloana a listei <ul>, dar aplica display: block pe elementele de legatura <a>. Acest lucru asigura ca intreaga latime a casetei devine zona interactiva clickabila, nu doar textul propriu-zis.

Principiile fundamentale de constructie a unui meniu vertical:

  1. Eliminarea stilului de lista: list-style: none; margin: 0; padding: 0; pentru a curata indentarea nativa a browserului.
  2. Transformarea link-urilor in blocuri (display: block): Permite aplicarea de padding vertical si orizontal si extinde zona clickabila pe toata latimea containerului.
  3. Feedback vizual la hover: Schimbarea culorii de fundal, deplasarea usoara cu padding-left sau transform: translateX() si evidentierea cu o bordura laterala (accent border).
  4. Starea activa: Marcarea vizuala a paginii pe care se afla utilizatorul in prezent (clasa .activ).

Demonstratie practica: Doua stiluri de meniuri verticale

Varianta 1: Meniu Vertical Clasic (Light)

Stil curat de navigare laterala cu bordura stanga la hover:

  • HOME
  • PRODUSE
  • DESPRE NOI
  • CONTACT
Codul CSS cheie:
#meniu-vertical-clasic a {
    display: block;
    text-decoration: none;
    color: #1e293b;
    padding: 12px 18px;
    border-left: 4px solid transparent;
    transition: all 0.2s ease;
}
#meniu-vertical-clasic a:hover {
    color: #2563eb;
    background-color: #f8fafc;
    border-left-color: #2563eb;
    padding-left: 22px;
}

Varianta 2: Bara Laterala Moderna (Dark)

Design cu fundal intunecat, colturi rotunjite si indicator de elemente:

Navigare Proiect
  • HOME Start
  • PRODUSE 12
  • DESPRE NOI Info
  • CONTACT @
Codul CSS cheie:
#meniu-vertical-dark a {
    display: flex;
    justify-content: space-between;
    text-decoration: none;
    color: #cbd5e1;
    padding: 10px 14px;
    border-radius: 8px;
    transition: all 0.2s ease;
}
#meniu-vertical-dark a:hover {
    color: #ffffff;
    background-color: #1e293b;
    transform: translateX(4px);
}
