Meniu Vertical

Construirea unui meniu vertical utilizand display: block pe elementele de legatura <a>.

Principii de constructie:

  1. Eliminarea stilului de lista: list-style: none; margin: 0; padding: 0;
  2. Transformarea link-urilor in blocuri (display: block): extinde zona interactiva pe toata latimea.
  3. Efect hover: schimbarea fundalului si deplasare usoara cu padding-left sau transform: translateX().

Demonstratie: Doua stiluri de meniuri verticale

Cod CSS:
#meniu-vertical-clasic a {
    display: block;
    text-decoration: none;
    color: #1e293b;
    padding: 12px 18px;
    border-left: 4px solid transparent;
    transition: all 0.2s ease;
}
#meniu-vertical-clasic a:hover {
    color: #2563eb;
    background-color: #f8fafc;
    border-left-color: #2563eb;
    padding-left: 22px;
}
