LABORATOR 2: DHTML

Lucrul cu foi de stiluri in cascada (Cascading Style Sheets - CSS)

Obiective conform fisei de laborator:
  1. Verificarea celor trei modalitati de precizare a stilului (inline, intern/antet, extern).
  2. Studierea mostenirii si a rezolvarii conflictelor in cadrul stilurilor CSS.
  3. Crearea unui meniu orizontal si a unui meniu vertical.
Cerinta 1

Modalitati de precizare a stilului

Studiul si testarea celor trei moduri de aplicare a foilor de stil: inline (atributul style), intern (tag-ul style in head) si extern (fisier separat legat prin link).

  • • 1.1 Stil Inline (atributul style)
  • • 1.2 Stil in Antet (tag-ul <style>)
  • • 1.3 Foaie Externa (css3.css cu <link>)
  • • Sinteza comparativa a celor 3 metode
Cerinta 2

Mostenire si rezolvarea conflictelor

Mecanismul de transmitere ierarhica prin arborele DOM (overriding inheritance), regulile de specificitate, prioritatea !important si toate tipurile de selectori din laborator.

  • • 2.1 Arborele DOM si mostenirea culorilor
  • • 2.2 Rezolvarea conflictelor & Selectori
Cerinta 3

Meniu Orizontal si Meniu Vertical

Constructia pas cu pas a meniului orizontal din lista <ul>, transformarea in meniu vertical cu display: block si integrarea intr-o macheta completa de site.

  • • 3.1 Meniu Orizontal (pasi 1 - 5)
  • • 3.2 Meniu Vertical (clasic & modern)
  • • 3.3 Macheta Integrata (Header + Sidebar)
