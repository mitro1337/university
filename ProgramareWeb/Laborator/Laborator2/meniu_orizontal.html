Exercitiul 3.1: Crearea si stilizarea unui meniu orizontal in CSS

Conform cerintei din laborator, transformarea unei liste neordonate <ul> intr-un meniu orizontal complet functional se realizeaza in pasi succesivi. Fiecare pas adauga o noua regula CSS pana la obtinerea meniului final.

Etapa 1: Lista HTML nativa neformatata

Lista verticala implicita cu marcatori (bullet-uri) si link-uri albastre subliniate:

  • HOME
  • PRODUSE
  • DESPRE NOI
  • CONTACT
Etapa 2: Eliminarea marcatorilor (bullet-urilor) si a spatiilor implicite
#meniu ul {
    margin: 0;
    padding: 0;
    list-style-type: none;
    list-style-image: none;
}

  • PRODUSE
  • DESPRE NOI
  • CONTACT
Etapa 3: Transformarea listei din verticala in orizontala cu display: inline
#meniu li {
    display: inline;
}
  • HOME
  • PRODUSE
  • DESPRE NOI
  • CONTACT
Etapa 4: Eliminarea sublinierii si schimbarea culorii implicite
#meniu a {
    text-decoration: none;
    color: red;
}
  • HOME
  • PRODUSE
  • DESPRE NOI
  • CONTACT
Etapa 5: Meniul final conform codului din laborator (cu efect de :hover) 
#meniu ul {
    margin: 0;
    padding: 0;
    list-style-type: none;
    list-style-image: none;
}
#meniu li {
    display: inline;
}
#meniu a {
    text-decoration: none;
    color: red;
}
#meniu a:hover {
    color: yellow;
}
