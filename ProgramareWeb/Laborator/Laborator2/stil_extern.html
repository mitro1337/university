Modalitatea 3: Importul unei foi de stil pastrata intr-un fisier separat

O foaie de stil externa se salveaza intr-un fisier cu extensia .css (in cazul nostru css3.css) si se conecteaza la documentul HTML prin intermediul etichetei <link rel="stylesheet" type="text/css" href="css3.css">. Aceasta este modalitatea recomandata conform standardelor web pentru separarea completa a prezentarii de continut.

Continutul fisierului extern css3.css:
em { background-color: #8000FF; color: white }
h1 { font-family: Arial, sans-serif }
p { font-size: 18pt }
.blue { color: blue }
Legarea in <head> prin elementul <link>:
<link rel="stylesheet" type="text/css" href="css3.css"/>

Avantajele majore ale foilor de stil externe:

  • Separare totala: Structura logica ramane in fisierul .html, iar regulile vizuale raman in fisierul .css.
  • Reutilizare globala: O singura foaie de stil poate controla aspectul a sute de pagini din intregul site web.
  • Performanta si memorare cache: Navigatorul descarca fisierul .css o singura data si il pastreaza in memoria cache pentru toate paginile vizitate ulterior.
  • Mentenanta rapida: Schimbarea paletei de culori sau a fontului pentru tot site-ul se face printr-o singura modificare in fisierul CSS.
